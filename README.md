# КРЪГОВРАТ

Търсим архив на изказванията на **Георги Сираков (Г. Д. Серафиос)**.

Не е аватар и не говори от негово име. Връща **какво е казал**, дословно,
с линк към видеото на точната секунда. Ако не е засягал темата — казва го.

---

## Защо така

Езотеричната терминология е точно материалът, върху който езиковите модели
съчиняват най-убедително. Затова тук всяко твърдение носи източник, а прагът
на отказ е част от системата, не изключение. По-полезно е да чуеш „не е
говорил за това“, отколкото правдоподобна измислица в негов стил.

## Слоеве

| Слой | Какво е |
|---|---|
| **Сегмент** | атом: 400–700 знака дословен текст + източник + таймкод |
| **Термин** | извлечено: всички дефиниции на едно понятие, подредени по дата |

Енциклопедията е вторият слой. Първият е само суровина.

## Пайплайн

```
sources.json  →  transcribe.py  →  work/raw/*.json  →  chunk.py  →  data/segments/*.json
   (URL-и)        yt-dlp+whisperX     ASR+диаризация      чънкване      готови сегменти
```

1. `ingest/sources.json` — списък с видеа/текстове, попълва се ръчно
2. `ingest/transcribe.py` — сваля аудио, транскрибира (`large-v3`, `bg`), диаризира
3. `ingest/speakers.json` — кой SPEAKER_xx е Сираков (по подразбиране: най-многото време)
4. `ingest/chunk.py` — реже на сегменти, маркира ниска увереност
5. ръчен преглед на `low_conf` → `human_checked: true`

**Транскрипцията иска GPU.** Colab (безплатен T4) минава ~1 час аудио за ~5 мин.
Локално на CPU е неизползваемо бавно.

и наследници. `data/` не влиза в git — стои в R2 зад secret.
